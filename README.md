# sihe-assets

Archive site for the Satcher Health Leadership Institute (SHLI), published via GitHub Pages at:

**https://satcherinstitute.github.io/sihe-assets/**

## What this is

A permanent home for content from concluded SHLI programs that would otherwise be lost to link rot when a third-party platform (like Constant Contact) eventually takes it down. This isn't an active project with an ongoing pipeline — it's a static archive.

## Ending the HIV Epidemic (EHE) / Georgia Thrives Newsletters

The "End the Epidemic" monthly newsletter series ran under Gilead Sciences funding as part of the Georgia Thrives / Ending the HIV Epidemic campaign. That funding has closed out, and the media agency that produced these newsletters is no longer doing work for SHLI — so this collection is final. There won't be new entries added to this folder.

**[Browse all 24 newsletters below](#newsletter-archive) →**
